QtParted 1.0.0 is a complete rewrite of QtParted for **Qt 6**, ten years after 0.6.0. Its new core is modelled on [GParted](https://gparted.org) 1.8: the same operation model, the same file system rules and the same safety checks, in a native Qt Widgets application without KDE Frameworks.

![QtParted main window](https://raw.githubusercontent.com/zanac/qtparted/main/doc/screenshots/main.png)

## Highlights

- **Plan first, apply once.** Every change is queued and previewed on the disk map; undo or clear before anything is written. The apply dialog shows each step and command with its live output, and saves the log as HTML.
- **Partition tables and partitions:** gpt, msdos and every libparted table type; primary, extended and logical partitions aligned to MiB, cylinders or sectors; delete, format, flags, GPT names.
- **Resize, move, copy and paste**, including logical and extended partitions. File systems are resized with their own tools (or libparted for FAT/HFS), moved with a block copy that is rolled back on failure, grown online when mounted.
- **Check, label and new UUID** for 21 file systems: bcachefs, btrfs, exfat, ext2/3/4, f2fs, fat16/32, hfs/hfs+, jfs, linux-swap, LVM2 PV, minix, nilfs2, ntfs, reiser4, reiserfs, udf, xfs.
- **LUKS:** open and close encrypted partitions, resize them together with the file system inside, check/label/format their content.
- **Mount on / unmount, swapon / swapoff, LVM Volume Group activation.**
- **Safety:** busy partitions are protected; before each operation the target is checked again on disk and in the kernel, so nothing is written if something changed in the meantime.
- **Italian translation**, built-in **user manual** (F1), pkexec launcher with Wayland and X11 support.

See the [README](https://github.com/zanac/qtparted#readme) for the full feature tour and the [ChangeLog](https://github.com/zanac/qtparted/blob/main/ChangeLog).

## Known limitations

- LUKS and LVM were tested end to end on loop devices with a test double for `cryptsetup`/`dmsetup` (the development system has no device-mapper) and on the CI runners; please report any problem on real hardware.
- Creating LUKS encryption and pasting encrypted content into a new partition are not supported yet (as in GParted).
- Only English and Italian are included; new translations are welcome (`translations/`).

**Back up your data before changing partitions.**
