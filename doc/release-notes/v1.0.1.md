QtParted 1.0.1 is a small update to [1.0.0](https://github.com/zanac/qtparted/releases/tag/v1.0.0), released the same day.

## Changes

- **Application icons repaired.** The PNG icons inherited from QtParted 0.6.0 had been damaged years ago by a text-mode (CRLF) conversion, so desktops and the About dialog could not show them. They are restored byte for byte from the original files, using the PNG checksums.
- **Four new languages:** German, French, Portuguese and Brazilian Portuguese, next to English and Italian. The menu entry, the administrator password prompt and the AppStream summary are translated too.

The translations were checked automatically (placeholders, markup, keyboard accelerators); corrections from native speakers are welcome in `translations/`.
